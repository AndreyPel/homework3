# Домашнее задание к работе 3

## Условие задачи

Написать и отладить программу пересчета из фунтов в кг, граммы и тонны.

## 1. Алгоритм и блок-схема
### Алгоритм решения
1. **Начало**
2. Ввод: Запросить у пользователя ввод массы в фунтах (pounds).
3. Вычисление 1: Перевести фунты в килограммы по формуле: 
 - kg = pounds * 0.453592.
4. Вычисление 2: Перевести килограммы в граммы по формуле: 
 - grams = kg * 1000.
5. Вычисление 3: Перевести килограммы в тонны по формуле: 
 - tons = kg / 1000.
6. Вывод: Вывести на экран полученные значения 
 - kg,
 - grams,
 - tons.
7. **Конец**
